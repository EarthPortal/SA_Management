\section{Introduction}

In this short report, our goal is to consider the JSON file that lists the metadata properties
read by O'FAIRe~\cite{ofaireconfig} and to convert it into a human-readable format. The
questions of O'FAIRe name a property in one way and the portal stores it under another, so I
need this list at hand to move from one name to the other during my internship.

% =====================================================================
\section{Development}

\subsection{The file}

The file is called \prop{properties.config.json}. I took it from the source code of
O'FAIRe~\cite{ofaireconfig}, as it was on 4 June 2026. It holds 123 entries, one per property.
Each entry gives the information of Table~\ref{tab:fields}.

\begin{center}
\small
\renewcommand{\arraystretch}{1.2}
\begin{tabular}{@{}l>{\raggedright\arraybackslash}p{13.6cm}@{}}
\toprule
\textbf{Field} & \textbf{What it says} \\
\midrule
\prop{portal} & The name of the property in the portal. O'FAIRe keeps the part after the colon and
  uses it to find the value in the answer of the portal API (for example \prop{omv:hasLicense}
  gives \prop{hasLicense}). \\
\prop{mod} & The MOD~1.4 name of the same property. It is the name used in the lists of the
  questions file. \\
\prop{type} & \prop{string} for a single value (109 entries) or \prop{array} for several values
  (14 entries). \\
\prop{source} & The part of the API answer where the value is read: the submission
  (99 entries), the ontology record (5), the metrics (10), or the links of the ontology record
  (9). \\
\prop{key} & Present in 4 entries only. For \prop{bpm:contact}, it asks for the name of each contact.
  For three metrics, it is the name under which the portal gives the number (\prop{classes},
  \prop{individuals}, \prop{properties}). \\
\bottomrule
\end{tabular}

Java code.}
\label{tab:fields}
\end{center}

\section{Conclusion}
Below are some observations that may be useful soon or later in my internship.

\begin{itemize}
  \item 71 entries have the same name on both sides; the other 52 are stored by the portal under
    a name that differs from the MOD name.
  \item The portal name \prop{bpm:notes} appears twice: it is given for \prop{rdfs:comment} and
    again for \prop{schema:comment}.
  \item Two MOD names are in no list of the questions file. They are \prop{mod:averageChildCount} and
    \prop{vann:changes}.
  \item In the other direction, the list of F2Q3 names \prop{void;classPartition} (with a semicolon),
    which is not in this file; the file has \prop{void:classPartition}.
\end{itemize}
