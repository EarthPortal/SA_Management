\section{Introduction}

In this short report, our goal is to consider the JSON file that contains the O'FAIRe
questions~\cite{ofaireconfig} and to convert it into a human-readable format. This should make
life easier and the questions better understood, since I will be using them throughout my
internship.

% =====================================================================
\section{Development}

\subsection{The file}

The file is called \prop{questions.config.json}. I took it from the source code of
O'FAIRe~\cite{ofaireconfig}, as it was on 4 June 2026. It follows the grid of the O'FAIRe
paper~\cite{amdouni2022faire}: the four FAIR principles are divided into 15 sub-principles, and
each sub-principle has its own questions, 61 in total. For every question, the
file gives:
\begin{itemize}
  \item the text of the question;
  \item the possible answers, each with its points;
  \item for 38 questions, the list of the metadata properties that the question looks at.
\end{itemize}

Each sub-principle also carries two numbers. The first, \prop{maxCredits}, is its weight in the
final score. The second, \prop{portalMaxCredits}, is described in the documentation of O'FAIRe
as the maximum that can be obtained in AgroPortal with the current implementation.
Table~\ref{tab:overview} gives both.
